これは何か

PSD のテキストレイヤを一覧して書き換えるツール。Photoshop を開かずに、 翻訳・校正・表記ゆれ修正といったテキストの再編集を行う。

編集していないレイヤはバイト単位でそのまま保存されるので、 画像レイヤや効果には一切影響しない。

画面の見かた

左: レイヤ
PSD のレイヤ構造。▾ で階層の折り畳み、👁 で表示の ON/OFF。フォルダの 👁 は配下ごと効く。 この ON/OFF はプレビュー専用で PSD には保存されない (「元に戻す」で PSD が持っている表示状態へ戻る)。 T のアイコンが付いているのがテキストレイヤ。 ● は未保存の変更あり。
中央: プレビュー
表示 ON/OFF を反映した合成結果。100% は実ドット等倍 (画像 1px = 画面 1 デバイス px) で、システムの表示スケールが 200% でも 倍サイズにはならない。「全体」でウィンドウに収まる倍率へ。
右: 編集
選択したテキストレイヤの本文。書式は本文中のタグで表す。 反映を押すまで文書には取り込まれない。

基本の流れ

  1. 開く… で PSD を選ぶ (起動時に psdtext foo.psd でも可)
  2. 左のツリーからテキストレイヤを選ぶ
  3. 右のペインで本文を書き換える
  4. 反映 (Ctrl+Enter) で文書へ取り込む
  5. 保存 (Ctrl+S) でファイルへ書き出す

「反映」はメモリ上の文書を書き換えるだけ。ファイルに書かれるのは「保存」を 押したとき。上部の「未保存 N」が反映済みで未保存の件数。

書式タグ

PSD のテキストは「ラン (連続する文字に同じ書式)」の並びで書式を持つ。 これを本文の中にタグとして畳み込んでいる。 

これは[b]太字[/b]で[size=96]大きい[size=48]文字
[color=#FF0000]赤い文字[color=#000000]黒に戻す
[align=center]中央揃えの段落

閉じタグは無い。タグはその位置から先の状態を変え、次の指定まで 効き続ける。戻すときは値を指定し直すか [/xxx] を使う。 PSD のランは入れ子ではなく平坦な並びなので、この形が構造にそのまま対応し、 入れ子を壊す事故も起きない。

[color=#FF0000]文字色

[/b] [/i] [/u]同じく off
[/font] [/size] [/color]その属性を基準へ戻す
[reset]全属性を基準へ戻す

基準は「先頭ランの書式」。そこから変わる箇所にだけタグが出るので、 書式が一様なテキストにはタグが 1 つも付かない。 普通の翻訳作業ではタグを意識しなくてよい。

書けなかったタグや壊れたタグは、そのままの文字として残る (本文が消えることは無い)。 解釈できなかったものがあれば編集欄の下に警告が出る。

行揃え・フォント・サイズ

行揃えボタン
段落に直接効く (タグを手で書かなくてよい)。 段落ごとに変えたい場合は本文中に [align=...] を置く。
フォント
候補はその PSD が持っているフォント。それ以外を使いたいときは ＋ でシステムフォントから追加する。選ぶと編集欄の選択範囲に [font=...] が入る。 Photoshop 側にも同じフォントが必要で、無い場合は Photoshop が 代替フォントで表示する。
サイズ / B / I / U
編集欄で範囲を選んでからボタンを押すと、その範囲にタグが入る。 選択していないときはカーソル位置から先に効く。 タグの内側を選んでいた場合は、タグを壊さないよう外側へ寄せてから囲む。

レイヤの操作

名前の変更
ツリーの名前をダブルクリック、または選択して F2 (「名前」ボタンでも可)。Enter で確定、Esc で取り消し。 テキストレイヤ以外にも使える。
複製 (= 新規追加)
選択中のテキストレイヤを複製する。ダイアログで名前と本文をその場で 決められるので、本文を書き換えれば実質「新規テキストレイヤの追加」 になる (ボタンを分けていないのはこのため)。
  • フォント・サイズ・色・位置・流し込み枠は複製元を引き継ぐ (位置を変えたい場合は Photoshop 側で移動する)
  • 中身をゼロから組み立てる方式ではないので、 テキストレイヤが 1 つも無い PSD には追加できない
テキストの位置と枠
右ペインの「位置」「枠」で数値指定できるほか、次の方法でも動かせる:
  • プレビュー上でドラッグ — 選択中のテキストレイヤの矩形の中を 掴んで動かす
  • 矢印キーで 1px、Shift+矢印で 10px (編集欄にカーソルが無いとき)
「位置」は文書上の座標、「枠」はテキストの流し込み枠の大きさ。 枠を変えて実際に流し込みが変わるのは段落テキストで、 ポイントテキストでは Photoshop 側が字形から枠を作り直す。 位置を動かすと PSD 内蔵のラスタも一緒に動くので、開き直すまでの間も 見た目がずれない。
移動 (▲▼)
同じ階層の中でひとつ上/下へ動かす。フォルダを選んでいるときは 中身ごと動く。階層をまたぐ移動 (フォルダへの出し入れ) はしない ので、それが必要なときは Photoshop 側で行う。 端まで来ていると「これ以上動かせません」と出る。

CSV で一括編集

CSV 書き出しで次の形式のファイルが得られる (UTF-8 BOM 付き / CRLF なので Excel でそのまま開ける)。 

lyid,path,text
2,"dialog/名前","こんにちは"
4,"dialog/本文","1 行目
2 行目"
  • text 列のセル内改行がそのまま段落区切りになる
  • text 列には書式タグをそのまま書ける
  • 照合は lyid (Photoshop の永続レイヤ ID) が主キー。 レイヤの並べ替えや改名をしても対応が壊れない。 lyid が無い行は path 列で照合する (同名レイヤが複数あると曖昧なので「未解決」として報告する)
  • 列の順序は自由で、余分な列があっても無視される

CSV 読み込みは最初に確認だけを行い、変更 / 同一 / 未解決の 件数と内訳を出す。内容を見てから「反映する」を押すと文書へ取り込まれる (この時点ではまだメモリ上。ファイルへ書くのは「保存」)。

保存の仕組み

  • 上書き保存すると、元ファイルは <名前>.psd.bak へ退避される (既存の .bak は上書きしない)
  • 保存ダイアログでパスを入れると別名保存。以後はそちらを編集する
  • 編集していないレイヤはバイト単位でそのまま書き出される
  • 表示 ON/OFF はプレビュー用なので保存されない

できないこと (プレビューの限界)

中央のプレビューは作業用の簡易合成であって、Photoshop の描画結果とは 一致しない。最終確認は必ず Photoshop で行うこと。

合成でできないこと

  • 調整レイヤ (トーンカーブ / 色相彩度 など) は反映されない
  • レイヤ効果 (ドロップシャドウ / 光彩 / 境界線 など) は反映されない
  • グループ (フォルダ) のブレンドモード・不透明度は反映されない
  • ブラウザに相当が無いブレンドモード (ビビッドライト / リニアライト / ピンライト / 焼き込みリニア など) は 近いモードで代用している
  • ベクトルマスクは未対応 (レイヤマスクは反映される)

テキスト仮描画でできないこと

PSD が持っているテキストの画像は Photoshop で開き直すまで更新されないので、 編集したテキストレイヤはブラウザ側で描き直して重ねている。これも近似:

  • 字詰め (カーニング / トラッキング) ・禁則処理は再現しない
  • 縦書きは横書きとして描かれる
  • 変形 (回転 / 拡大縮小 / ワープ) は反映されない
  • 行送りは「最大文字サイズ × 1.4」の概算
  • 枠に対する自動折り返しはしない (長くすると枠からはみ出る)
  • この PC に入っていないフォントは代替表示になる (編集欄に注記が出る)

編集でできないこと

  • テキストレイヤの追加は既存レイヤの複製が土台 (「新規追加」参照)。雛形が無い PSD — つまりテキストレイヤが 1 枚も 無い PSD — には追加できない
  • 位置と流し込み枠を変えられるのはテキストレイヤだけ。 画像レイヤの移動や拡大縮小は Photoshop 側で行う
  • テキストの回転・変形はできない (変換行列のうち移動成分だけを扱う)
  • 重ね順の変更は同じ階層の中だけ。フォルダへの出し入れはできない
  • 保存後の合成プレビュー画像 (Photoshop が持つサムネイル) は古いまま

自動化 (REPL)

--repl (対話) / --replfile=DIR (エージェント / CI) / POST /_app/repl (curl) から操作できる。

.psd開いている文書の情報
.textsテキストレイヤ一覧 (* が未保存)
.settext <index> <text>本文を差し替える
.b state画面の状態を覗く
.b call select 3レイヤを選ぶ
.b call rename {"index":1,"name":"新名"}レイヤ名を変える
.b call move {"index":3,"up":true}重ね順を動かす
.b call place {"x":200,"y":120}テキストの位置
.b call place {"width":320,"height":180}テキストの枠
.b call duplicate {"name":"新","text":"本文"}複製 / 追加
.b call lang ja表示言語を切り替える
.b call save保存

HTTP API の一覧は README を参照。すべて X-App-Token ヘッダが要る。
